# Fault Sentinel
### Machine Learning-Based Fault Detection, Classification and Early Fault Prediction in Electrical Distribution Networks

Undergraduate research project, BSc (Hons) Computer Science, NSBM Green University, Sri Lanka.
Supervisor: Dr. Pabudi Abeyrathne

---

## Overview
Fault Sentinel is a three-module machine learning system for handling faults in power distribution networks. It combines **fault detection**, **fault classification** and **graduated multi-horizon early fault prediction** in one unified framework. To our knowledge, no existing study covers all three together.

Aligned with **SDG 7** (Affordable and Clean Energy) and **SDG 9** (Industry, Innovation and Infrastructure).

## System Modules

| Module | Task | Final Model |
|---|---|---|
| 1. Detection | Binary: Normal vs Fault | XGBoost |
| 2. Classification | 11-class fault / disturbance type | Random Forest |
| 3. Early Prediction | 10-class, 60 / 30 / 15-minute warning tiers | Hybrid LSTM + XGBoost (weighted soft voting) |

## Input Features
Nine electrical measurements are used across all modules:
`Va_kV`, `Vb_kV`, `Vc_kV`, `Ia_A`, `Ib_A`, `Ic_A`, `Active_Power_MW`, `Reactive_Power_Mvar`, `Frequency_Hz`

## Dataset
Data was generated by simulating an **IEEE 13-bus feeder in OpenDSS**, rebased to 11 kV / 400 V to match Sri Lankan distribution standards. Simulations were driven from Python using OpenDSSDirect.py, monitoring Bus 675.

| File | Rows | Description |
|---|---|---|
| `detection.csv` | 7,000 | Binary label |
| `classification.csv` | 2,550 | 11 classes |
| `predictionData_opendss.csv` | 43,200 | 720 episodes × 60 timesteps, gradual fault progression, 10 classes |

**Classification classes (11):** HRGF, LL Fault, LLG Fault, LLLG Fault, Normal, Overcurrent Conditions, Overload, SGF/LG Fault, Transformer Abnormalities, Voltage Sag, Voltage Swell.

A Kaggle dataset was also tested for cross-validation, but it was incompatible (instantaneous waveform data vs. RMS features), so it is documented as a limitation.

## Methodology
- Quantitative research, positivist paradigm, deductive approach
- Random seed `42` throughout
- 5-fold Stratified Cross-Validation for all three models
- Hyperparameter tuning with GridSearchCV (Modules 1 and 2)
- **Module 3 (leak-free protocol):** episode-level `GroupShuffleSplit` for both the outer (train/test) and inner (train/validation) splits. Ensemble weights are tuned on the validation set only. Window size = 10.

## Results

### Module 1: Detection (XGBoost)
| Accuracy | Precision | Recall | F1 | ROC-AUC |
|---|---|---|---|---|
| 95.00% | 98.90% | 90.88% | 94.72% | 97.12% |

Hyperparameters: 200 estimators, max depth 6, learning rate 0.1, subsample 0.9.

### Module 2: Classification (Random Forest)
| Accuracy | Precision | Recall | F1 | ROC-AUC |
|---|---|---|---|---|
| 95.88% | 95.99% | 95.88% | 95.84% | 99.75% |

Hyperparameters: 200 estimators, unrestricted depth. Weakest class: LL Fault (67% recall).

### Module 3: Early Prediction
| Model | Accuracy | Precision | Recall | F1 | ROC-AUC |
|---|---|---|---|---|---|
| **Hybrid LSTM + XGBoost** | **93.78%** | 93.85% | 93.78% | 93.69% | 99.79% |
| XGBoost (standalone) | 93.63% | 93.69% | 93.63% | 93.54% | 99.79% |
| LSTM (standalone) | 90.75% | 91.20% | 90.75% | 90.80% | 99.69% |

- XGBoost: 400 estimators, depth 7, learning rate 0.08
- LSTM: 2 layers (64, 32 units), dropout 0.2, dense 32, softmax, Adam, up to 40 epochs, batch size 64, early stopping (patience 5)
- Hybrid voting weights vary slightly between runs because LSTM training is non-deterministic. Hybrid accuracy stays in the 93.7–93.8% range.

## Limitations
- Training data is simulated (OpenDSS), not from a real utility network
- Evaluated on a single feeder topology (IEEE 13-bus)
- LL Fault class has comparatively low recall
- Cross-validation on an external real-world dataset was not possible due to feature incompatibility
